# PRODUCT.md — CuinCStructLab 产品定义

## 1. 产品定位

**CuinCStructLab** 是一个面向 C 语言初学者的**数据结构学习、可视化、代码实践与刷题平台**。

一句话描述：**"看得见指针、跑得动代码、刷得了题"的数据结构学习桌面应用。**

产品不是 Demo，而是可以长期用于学习数据结构的完整工具：

- 课程：从 C 预备知识到图、排序的 14 章系统学习路线
- 可视化：统一可视化引擎，动画 + 单步执行 + 可回退
- 代码：真实 C 语言实现，逐行讲解，代码行 / 变量 / 画面三者同步
- 刷题：章节练习（8 种题型）+ 编程题 + 本地自动判题
- 记录：错题本、学习进度、知识掌握度、笔记与收藏，本地持久化

## 2. 目标用户

| 用户画像 | 描述 | 核心诉求 |
| --- | --- | --- |
| 大一 CS 学生 | 刚学完 C 语言基础语法，正在学数据结构课程 | 看懂指针与链表，应付课程与考试 |
| 考研/复试准备者 | 需要系统过一遍数据结构 | 系统路线 + 刷题 + 复杂度 |
| 自学者 | 用 C 语言自学数据结构 | 不掉坑：内存、指针、边界 |
| 转行者 | 只有简单编程经验 | 类比 + 新手模式 + 逐行解释 |

**明确非目标用户**：熟练工程师、需要 STL/高级语言数据结构的人。

## 3. 核心价值主张

1. **指针可视化**：链表插入/删除逐指针变化展示；内存面板（变量/模拟地址/值/指针箭头）；递归调用栈可视化。
2. **三者同步**：C 代码行高亮 ↔ 变量监视 ↔ 数据结构画面，任何时刻一一对应。
3. **可回退动画**：Play / Pause / Next / Previous / Restart / 0.25x–4x 变速 / Jump To Step。Previous 基于快照，绝不"猜测状态"。
4. **真实 C 代码**：所有实现都是初学者友好的、注释充分的真实 C 代码，配逐行解释。
5. **闭环学习**：学（课程）→ 看（可视化）→ 练（Playground 互动）→ 测（练习题）→ 写（编程题判题）→ 记（错题本/掌握度）。

## 4. 功能总览

### 4.1 课程系统（14 章）
Chapter 0 C 预备知识 → 1 复杂度 → 2 顺序表 → 3 单链表 → 4 双向链表 → 5 栈 → 6 队列 → 7 字符串与数组 → 8 树 → 9 BST → 10 堆 → 11 图 → 12 查找 → 13 排序。
每章遵循统一 14 段教学结构（是什么/为什么/类比/图示/C 定义/操作/逐行代码/动画/单步/复杂度/空间/常见错误/小测验/编程练习）。

### 4.2 可视化实验室（Playground）
数组、链表、双向链表、栈、队列、树、BST、堆、图、排序 全部可由用户输入数据、选择操作、动画执行。

### 4.3 练习与刷题
- 章节练习：单选/多选/判断/填空/代码阅读/执行结果/找 Bug/代码补全
- 编程题：题目 + 函数签名 + 初始模板 + 示例 + 测试用例 + 本地判题
- 判题状态：Accepted / Wrong Answer / Compile Error / Runtime Error / Time Limit Exceeded

### 4.4 学习记录
- 错题本：错误分类（概念/指针/边界/循环/内存/算法理解/复杂度）、错误次数、最近错误时间、重练、标记掌握
- Dashboard：课程完成度、正确率、编程题完成度、错题数、连续学习天数、最近学习、知识点掌握
- 知识掌握度：未学习 / 学习中 / 待加强 / 基本掌握 / 已掌握（规则驱动，无 AI API）
- 搜索：知识点/数据结构/算法/题目
- 收藏与笔记：本地保存

## 5. 技术形态

- 桌面优先（Dark Mode 优先），Electron 外壳可选启用
- 浏览器开发模式同样完整可用（数据持久化到 IndexedDB）
- 所有学习数据保存在本地（SQLite），无任何云依赖、无账号
