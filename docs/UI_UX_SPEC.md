# UI_UX_SPEC.md — UI/UX 规格

## 1. 总体

- 风格：现代、简洁、学习型；桌面优先（设计基准 1440×900，最小可用 1024×680）。
- **Dark Mode 优先**（默认暗色），支持 Light 切换；CSS 变量实现主题，`data-theme` 属性切换。
- 主色调：暗色底 `#14161c` 系列，强调色靛蓝 `#5b8cff`；语义色：比较黄 `#e6b450`、交换红 `#e0564f`、已排序绿 `#58c989`、pivot 紫 `#a371f7`、当前蓝 `#5b8cff`。
- 中文界面；等宽字体展示代码（JetBrains Mono / Consolas / ui-monospace 回退链）。

## 2. 导航（左侧固定侧栏）

首页 / 课程 / 数据结构 / 算法 / 可视化实验室 / 代码练习 / 题库 / 错题本 / 学习统计 / 设置
（顶部条：全局搜索框 + Beginner Mode 快捷开关 + 主题切换。HashRouter。）

## 3. 页面规格

### 3.1 课程页（核心页面）
```
┌────────┬──────────────────────────────┬───────────────┐
│ 课程目录 │  正文（14 段教学结构滚动区）      │ 变量/内存/      │
│ (章节树) │  - 图文 + C 代码(CodePanel)     │ 数据结构状态     │
│        │  - 动画操作卡片(打开 Visualization)│ (右侧状态栏)    │
├────────┴──────────────────────────────┴───────────────┤
│              播放器（Play/Pause/Prev/Next/进度/速度/单步说明） │
└─────────────────────────────────────────────────────────┘
```
- 右侧栏 Tab：变量 / 内存 / 调用栈（按操作类型显示相关 Tab）。
- 小测验小节直接内嵌练习组件；编程练习小节链接到代码练习页并预选题目。

### 3.2 可视化实验室（Playground）
- 左：选择数据结构（Array/LinkedList/Doubly/Stack/Queue/Tree/BST/Heap/Graph/Sorting）。
- 中：可视化画布 + 操作面板（操作下拉 + 参数输入 + 执行按钮）+ 数据初始化输入。
- 底：播放器 + 当前步说明；Compare Mode 在 Sorting 下启用（2–3 算法并排）。

### 3.3 题库 / 错题本
- 筛选：章节 / 题型 / 难度 / 错因 / 掌握状态；列表 + 答题面板。
- 错题本卡片显示：知识点、错误次数、最近错误时间、错误类型徽章、重练/标记掌握按钮。

### 3.4 代码练习
- 左：题目列表（状态点：未做/已通过/尝试过）；中：题面；右/下：CodeMirror 编辑器 + "运行判题"按钮 + 结果面板（状态徽章 + 用例表：输入/Expected/Actual）。

### 3.5 首页 / 学习统计
- 首页：继续学习（最近章节）、总览卡片（完成度/正确率/连续天数/错题数）、快捷入口。
- 统计页：章节进度条列表、知识点掌握分布、正确率趋势（近 30 天按日聚合）、编程题完成度。

### 3.6 设置
- 主题、Beginner Mode、动画基准速度、Runner 编译器路径（覆盖自动探测）、导出/导入数据（JSON）、清空数据（二次确认）。

## 4. Beginner Mode（新手模式）

- 全局开关；开启后：每步 description 下追加 `beginnerNote`（更细的解释，"current 当前指向值为 10 的节点。current->next 保存下一个节点的地址。执行后…"）。
- CodePanel 行悬浮显示行级 beginner 解释；无 beginnerNote 时回退 note。
- 状态记忆入 settings。

## 5. 交互细节

- 播放器键盘快捷键：Space 播放/暂停、←/→ 单步、R 重置、↑/↓ 变速。
- 所有按钮有 title；破坏性操作（清空数据）二次确认。
- 加载/空态：题库空、无错题、无提交等提供引导性空态插画文案。
- 错误提示：toast（右上，自动消失）+ 关键错误（存储失败）常驻横幅。

## 6. 无障碍

- 语义化标签与 aria-label（播放器按钮、导航）；键盘可完成答题与播放全流程。
- 颜色对比：正文 ≥ 4.5:1；高亮色同时有形状/位置线索（不只靠颜色区分状态）。
- 尊重 `prefers-reduced-motion`：关闭步进过渡动画（快照直接切换）。
